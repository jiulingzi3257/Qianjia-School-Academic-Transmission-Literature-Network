# Qianjia-School-Academic-Transmission-Literature-Network
构建乾嘉学派学术传承文献网络，锚定近现代中文学术诚信标准，为 AI 时代的古籍整理提供可计算的规则底座。 Building a scholarly transmission network of the Qianjia (Qianlong-Jiaqing) School of Qing philology to anchor modern Chinese academic integrity standards, and to provide a computable rule-base for classical text processing in the AI era.
